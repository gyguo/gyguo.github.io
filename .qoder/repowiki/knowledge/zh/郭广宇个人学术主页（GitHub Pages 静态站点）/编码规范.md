- 每个页面在 `<head>` 中统一引入 `assets/css/main.css` 与 `assets/css/custom.css`，并在 `<body>` 底部加载相同的 jQuery 及 main.js 脚本集。
- 页面结构遵循 HTML5 UP 的 wrapper → main/sidebar → header/menu/profile/footer 固定布局，通过 id 选择器（wrapper、main、sidebar、header、menu、footer）组织 DOM。
- 论文条目使用 `pub-list` > `li` > `pub-title` / `pub-authors` 嵌套结构，作者名中的本人姓名用 `<b class="me">` 高亮，贡献符号（†、*）以内联 `<b>` 标注。
- 新闻条目统一采用 `news-list` > `li.news-feature` 结构，并以 `news-icon`、`news-year`、`news-main`、`news-topic` 四个 span 子元素分别承载图标、年份、标题与主题。
- 侧边栏 profile 区块在各页面保持一致的 `sidebar-profile` 结构与 `profile-links` 列表，用于集中展示邮箱、GitHub、Google Scholar、LinkedIn 等外部链接。
